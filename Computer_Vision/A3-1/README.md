# A3-1: 휴대폰으로 찍은 종이를 똑바르게 펴서 스캔하게 만들기

> **OpenCV를 활용한 엣지 검출, 윤곽선 추출, 원근 투영 변환(Perspective Transform) 및 적응형 이진화 기반 대화형 문서 스캐너 애플리케이션입니다.**

---

## 1. 프로젝트 개요

스마트폰 카메라로 비스듬하게 촬영된 문서, 영수증, 명함 등의 사각형 영역을 자동으로 인식하고, 원근 왜곡을 수학적으로 보정한 후 평판 스캐너로 읽은 듯한 선명한 흑백 스캔본을 생성하는 비전 시스템입니다.

- **학습 시간**: 60시간
- **주요 기술**: Python, OpenCV (`cv2`), NumPy, Canny Edge, Homography Perspective Transform, Adaptive Thresholding
- **구현 특징**:
  - 수학적 4개 꼭짓점 정렬 알고리즘 (좌상/우상/우하/좌하)
  - 실시간 파라미터 튜닝을 위한 대화형 OpenCV 트랙바 GUI 탑재
  - 실시간 웹캠 스트림 스캔 모드 지원
  - 20장 벤치마크 테스트셋 및 규칙 기반 CV 한계 분석 보고서 수록

## 3. 핵심 알고리즘 파이프라인

```
[입력 이미지]
      │
      ▼
1. Grayscale & Gaussian Blur (노이즈 평활화)
      │
      ▼
2. Canny Edge Detection (경계선 검출)
      │
      ▼
3. findContours & approxPolyDP (RDP 4점 근사 및 사각형 추출)
      │
      ▼
4. 4-Corner Ordering (합/차 트릭: TL, TR, BR, BL 정렬)
      │
      ▼
5. getPerspectiveTransform & warpPerspective (호모그래피 평면 보정)
      │
      ▼
6. Adaptive Thresholding (조명 얼룩 제거 및 흑백 글씨 선명화)
```

## 4. 실행 방법

### 1) 20장 정량 평가 벤치마크 실행
20장의 테스트 데이터셋에 대해 자동 스캔을 수행하고 성공률 표를 출력합니다.
```bash
python src/evaluate_scanner.py
```

### 2) 벤치마크 테스트셋 재생성 (필요시)
```bash
python src/generate_test_samples.py
```

### 3) 대화형 트랙바 GUI 실행 (이미지 모드)
슬라이더를 실시간으로 조절하며 블러 크기, Canny 임계값, 적응형 이진화 블록 크기를 튜닝할 수 있습니다.
```bash
python src/gui.py --image test_images/cond1_simple_1.jpg
```
- **단축키**:
  - `S`: 현재 보정된 고해상도 스캔본 저장 (`output/scan_result_*.png`)
  - `R`: 트랙바 파라미터 초기화
  - `Q` 또는 `ESC`: 프로그램 종료

### 4) 실시간 웹캠 스캐너 실행
웹캠에 문서를 비추면 초록색 윤곽선이 자동으로 추적되며, `S` 키 입력 시 즉시 캡처하여 스캔본을 저장합니다.
```bash
python src/gui.py --webcam
```

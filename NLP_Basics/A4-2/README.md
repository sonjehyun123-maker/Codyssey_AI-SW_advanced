# A4-2: 글 속에 숨은 정보와 기분(좋음/나쁨)을 자동으로 뽑아내기

> **정규표현식(Regex) 기반의 5대 엔티티 추출과 사전(Lexicon) 기반 감성 분석 및 규칙 기반 처리 시스템입니다.**

---

## 1. 프로젝트 개요
- **목표**: 5개 핵심 패턴(이메일, 전화번호, 날짜, 금액, URL) 정규식 추출, 부정어/강조어 처리 규칙 기반 감성 점수 산출기, 규칙 기반 접근법의 성공/실패 분석
- **학습 시간**: 70시간
- **주요 기술**: Python, Regex, Sentiment Lexicon, Rule-based Text Mining

---

## 2. 디렉터리 구조
```text
A4-2/
├── src/
│   ├── entity_extractor.py     # 5대 패턴 정규표현식 정보 추출 모듈

│   └── main.py                 # 텍스트 입력 처리 및 분석 실행 모듈
└── README.md                   # 정보 추출/감성 분석 성능 평가, 규칙 기반 성공/실패 사례
```

# A7-1 학습용 md
## 목적
- A7-1 파이널 팀 프로젝트(CV/NLP 자율 주제 End-to-End AI 서비스)를 체계적으로 기획, 개발, 배포하기 위한 프로젝트 가이드.

---

## 1. 프로젝트 생명주기 (Project Lifecycle)
1. **문제 정의 (Problem Definition)**: 사용자가 겪는 명확한 Pain Point 식별 및 AI 기술 적용의 정당성 확보.
2. **기획서 & 요구사항 명세**: 타겟 페르소나, 핵심 KPI, 기능적(FR) 및 비기능적(NFR) 요구사항 정의.
3. **아키텍처 설계**: 프론트엔드, API 백엔드, 모델 추론 엔진, 데이터 파이프라인의 구조도 작성.
4. **모델 개발 및 최적화**: 데이터 수집/정제, 모델 학습, 경량화(ONNX/양자화) 및 벤치마크.
5. **서빙 및 배포**: FastAPI/Flask 기반 RESTful API 구현, Docker 컨테이너화.
6. **동료 평가 및 회고**: Git 커밋 히스토리 관리, 코드 리뷰, 트러블슈팅 문서화.

---

## 2. 문서화 표준 템플릿
- **서비스 기획서 (`docs/기획서.md`)**: 문제 배경, 해결 방안, 시장 분석, 4주간의 스프린트 마일스톤.
- **요구사항 정의서 (`docs/요구사항_정의서.md`)**: 회원/인증, 입력 처리, 실시간 추론, 결과 반환, 응답 시간 목표.
- **시스템 아키텍처 (`docs/architecture.png`)**: 유저 요청 흐름과 데이터 파이프라인 시각화.

---

## 3. 팀 협업 컨벤션
- **Git Commit Convention**: `feat:`, `fix:`, `docs:`, `refactor:`, `test:`
- **PR & Code Review**: 모든 팀원이 의미 있는 커밋을 분담하고 머지 전 코드 리뷰 수행.

# A7-1: CV, NLP 자율 주제 파이널 프로젝트

> **컴퓨터 비전(CV) 또는 자연어 처리(NLP) 도메인의 실제 문제를 해결하는 End-to-End AI 서비스 팀 프로젝트입니다.**

---

## 1. 프로젝트 개요
- **목표**: 서비스 기획서 및 요구사항 정의서 작성, 시스템 아키텍처 다이어그램 설계, 풀스택 AI 서비스 구현 및 안정적 배포, 팀원 역할 및 커밋 기록 관리
- **학습 시간**: 80시간
- **주요 기술**: CV/NLP Deep Learning, Web API (FastAPI/Flask), Service Deployment, Git Collaboration

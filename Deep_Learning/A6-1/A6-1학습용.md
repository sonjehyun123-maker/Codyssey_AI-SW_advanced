### 2. 텐서(Tensor)란 무엇인가? (점, 선, 면, 큐브, 그리고 시공간의 보관함)
컴퓨터는 숫자만 압니다. 그런데 이 숫자들이 모여 사는 형태(차원)에 따라 부르는 이름이 다릅니다.

```
스칼라 (0D)        벡터 (1D)             행렬 (2D)                    3D 텐서 (3D)
    [ 7 ]      [ 1, 2, 3, 4 ]      [[ 1,  2,  3 ],         [ [[1,2], [3,4]],
                                    [ 4,  5,  6 ],           [[5,6], [7,8]] ]
                                    [ 7,  8,  9 ]]
   (점: 체온)    (선: 일주일 기온)    (면: 흑백 사진 픽셀)       (입체: 컬러 이미지, RGB 3겹)
```

- **0차원 텐서 (스칼라, Scalar)**: 크기만 있는 숫자 하나입니다. 예: 나의 오늘 체온 `36.5도`.
- **1차원 텐서 (벡터, Vector)**: 숫자를 한 줄로 나열한 기차입니다. 예: 지난 일주일간의 기온 `[21, 23, 20, 25, 22, 19, 24]`.
- **2차원 텐서 (행렬, Matrix)**: 숫자를 가로세로 바둑판처럼 배치한 엑셀 시트입니다. 예: 가로 28픽셀, 세로 28픽셀 크기의 흑백 손글씨 이미지.
- **3차원 텐서 (3D Tensor)**: 엑셀 시트 여러 장을 책처럼 겹쳐 놓은 것입니다. 예: 컬러 사진 한 장 (빨강, 초록, 파랑 3장의 2차원 판이 겹침: `3 × 28 × 28`).
- **4차원 이상 텐서 (N-D Tensor)**: 그런 책을 상자에 64권 담으면? `64 × 3 × 28 × 28` (미니배치 64개의 컬러 이미지 묶음). 동영상이라면 시간(프레임) 축이 하나 더 붙어 5차원 텐서가 됩니다.

### 3. 연산 그래프(Computational Graph): 요리 주문서 vs 실시간 요리
인공지능 모델이 입력을 받아 출력을 낼 때, 컴퓨터 내부에서는 덧셈과 곱셈이 거미줄처럼 이어집니다. 이 거미줄 지도를 **연산 그래프**라고 부릅니다.

1. **정적 그래프 (Static Graph - TensorFlow 1.x 방식)**:
   - **비유**: **"설계도 완벽히 그리고 착공하기"**
   - 레고를 조립하기 전에 설계도를 컴퓨터 화면에 완벽하게 그려서 확정짓습니다. 설계도가 승인되기 전에는 블록에 손도 못 댑니다. 중간에 "이 블록 색깔이 마음에 안 드네?" 하고 바꿀 수 없습니다. 성능 최적화에는 좋지만, 디버깅하기가 아주 답답합니다.
2. **동적 그래프 (Dynamic Graph - PyTorch Define-by-Run 방식)**:
   - **비유**: **"실시간 즉흥 요리 (블록을 끼우면서 조립하기)"**
   - 코드를 실행하는 바로 그 순간(Run)에 연산 그래프가 만들어집니다(Define). 파이썬의 `print()`문으로 중간 결과를 언제든 엿볼 수 있고, `if`문으로 그때그때 다른 연산을 할 수 있어 직관적이고 다루기 매우 쉽습니다.

### 4. Autograd(자동 미분)과 역전파: 도미노 역재생
- **정방향 연산(Forward)**: 도미노를 1번부터 100번까지 차례대로 쓰러뜨려 최종 목표지점(정답과 예측값의 오차)에 도달합니다.
- **역방향 연산(Backward)**: 마지막에 쓰러진 100번 도미노가 "나를 쓰러뜨린 힘이 99번에서 얼마나 왔고, 98번에서 얼마나 왔는가?"를 거꾸로 물어보며 1번 도미노까지 돌아가는 과정입니다.
- **위상 정렬(Topological Sort)**:
  - 도미노가 Y자로 갈라지거나 합쳐질 때, 어떤 도미노부터 순서대로 거꾸로 계산해야 꼬이지 않을까요?
  - "나에게 의존하는 다음 연산들이 모두 계산 끝났을 때만 나를 계산한다"는 약속으로 순서를 정렬하는 정리 기법입니다.

### 5. 주요 부품(Layer)들의 쉬운 역할
1. **Linear (선형 레이어, $Wx + b$)**:
   - **비유**: 가중치 곱셈기. 사과($x_1$) 3개와 바나나($x_2$) 2개의 총 가격을 계산하는 계산원 ($3 \times w_1 + 2 \times w_2 + \text{기본포장비 } b$).
2. **ReLU (활성화 함수)**:
   - **비유**: **"빚 탕감기"**. 가진 돈이 마이너스면 그냥 0원으로 리셋해주고, 플러스면 있는 그대로 살려둡니다. 단순하지만 딥러닝을 깊게 쌓을 수 있게 만든 기적의 스위치입니다.
3. **Sigmoid**:
   - **비유**: 어떤 숫자든 **0% ~ 100% 사이의 확률(0~1)**로 쥐어짜주는 압축기. "내일 비가 올 확률은 0.85야"라고 말할 때 쓰입니다.
4. **Softmax & CrossEntropy**:
   - **Softmax**: 10가지 보기(0~9 숫자)에 대해 모든 보기가 합쳐서 100%가 되도록 비율을 예쁘게 정규화해 주는 전광판.
   - **CrossEntropy**: "정답이 7번이었는데, 너는 7번에 몇 %를 걸었니?"를 보고, 엉뚱한 번호에 높은 확률을 걸었을수록 엄청난 벌점(Loss)을 매기는 무자비한 심판관.

### 6. 가중치 초기화: 첫 단추를 어떻게 꿸 것인가?
딥러닝 모델의 첫 출발점(초기 가중치 $W$)을 어떻게 정할까요?

1. **전부 0으로 초기화 (Zero Init)**:
   - **비유**: 모든 수험생에게 똑같은 옷, 똑같은 필통, 똑같은 지우개를 주고 똑같이 생각하라고 강요한 꼴.
   - 모든 노드가 똑같은 계산을 하고 똑같은 피드백을 받아서 **서로 다른 특징을 배울 수 없는 '쌍둥이의 저주(Symmetry Breaking 실패)'**에 빠집니다.
2. **그냥 아무 정규분포 난수 (Random Normal)**:
   - 너무 작게 주면 레이어를 통과할수록 신호가 사라져 버리고(기울기 소실), 너무 크게 주면 신호가 감당 못 할 만큼 커져서 터져버립니다(기울기 폭발).
3. **Xavier (Glorot) 초기화**:
   - 들어오는 입구 개수와 나가는 출구 개수를 고려해 신호의 크기가 줄어들지도 커지지도 않게 유지해 줍니다 (주로 Sigmoid, Tanh에 적합).
4. **He (Kaiming) 초기화**:
   - ReLU는 음수를 다 0으로 날려버리므로 신호의 절반이 사라집니다. 그래서 Xavier보다 **에너지를 2배 더 보충해 주는 방식**입니다 (ReLU 계열 모델의 표준).

### 7. 수치 미분 검증: 레이저 센서를 일반 자로 더블 체크하기
- 프레임워크를 직접 만들 때, 내가 손으로 유도한 역전파 미분 공식(해석적 미분, $f'(x)$)에 오타나 부호 실수가 있을 수 있습니다.
- 그래서 컴퓨터에게 고등학교 때 배운 평균 변화율 공식($\frac{f(x+\epsilon) - f(x-\epsilon)}{2\epsilon}$)으로 무식하게 살짝 건드려보게 시킵니다.
- 두 미분 값의 오차가 $0.0000001$($10^{-7}$) 이하로 거의 완벽하게 일치하면 "내 역전파 구현에 버그가 없구나!" 하고 안심할 수 있습니다.

## 1. Deep Learning Framework Architecture & Computation Engine

현환 딥러닝 프레임워크(PyTorch, TensorFlow, JAX)의 코어는 수치 선형 대수 라이브러리(BLAS, cuBLAS, OneDNN) 위에 구축된 **자동 미분(Automatic Differentiation, AD)** 및 **비순환 방향 그래프(Directed Acyclic Graph, DAG)** 실행 엔진입니다.

```
+-------------------------------------------------------+
|                Python Frontend API                    |
|      (Tensor, Module, Parameter, Optimizer, Functional) |
+-------------------------------------------------------+
                           |
+-------------------------------------------------------+
|            Dynamic Autograd Engine (DAG)              |
|   (Node, Edge, Backward Tape, Topological Sorter)     |
+-------------------------------------------------------+
                           |
+-------------------------------------------------------+
|           Tensor Storage & Strided Dispatch           |
|      (StoragePointer, Strides, Offset, MemoryPool)     |
+-------------------------------------------------------+
                           |
+-------------------------------------------------------+
|       Hardware Backends (CPU AVX-512, CUDA, ROCm)     |
+-------------------------------------------------------+
```

### 텐서(Tensor)의 메모리 레이아웃: Storage와 Stride
물리적으로 컴퓨터 메모리는 1차원 연속 버퍼(Flat Array)입니다. $N$차원 텐서는 이 1차원 버퍼를 논리적 다차원 인덱싱으로 사상(Mapping)하는 추상화 객체입니다.
- **Shape**: 각 차원의 크기 $(d_0, d_1, \dots, d_{k-1})$
- **Stride**: 각 차원에서 다음 인덱스로 한 칸 이동하기 위해 1차원 물리 메모리에서 건너뛰어야 하는 요소 수 $(s_0, s_1, \dots, s_{k-1})$
- 다차원 인덱스 $(i_0, i_1, \dots, i_{k-1})$가 가리키는 물리 주소 오프셋은 다음과 같습니다:
  $$\text{Offset} = \sum_{j=0}^{k-1} i_j \cdot s_j$$
- Row-major(C-contiguous) 기준 stride 공식:
  $$s_{k-1} = 1, \quad s_j = s_{j+1} \cdot d_{j+1} \quad (j = k-2, k-3, \dots, 0)$$

## 3. Autograd(자동 미분) 엔진 설계

### 3.1 Node, Creator, Backward Function
자동 미분 엔진은 역전파 테이프(Reverse-mode AD Tape) 구조를 채택합니다.
- `Tensor` 객체는 `data`(NumPy ndarray), `grad`(누적 기울기), `creator`(해당 텐서를 생성한 연산 노드, `Function` 객체), `requires_grad`(미분 추적 플래그)를 필드로 갖습니다.
- `Function` 추상 기본 클래스는 `forward(*args)`와 `backward(grad_output)`를 구현합니다.

### 3.2 위상 정렬 (Topological Sorting) 알고리즘
손실 스칼라 노드 $L$로부터 리프 노드(Leaf Tensors: 가중치, 편향)까지의 역방향 순회는 DAG의 위상 정렬 역순으로 수행되어야 합니다. 그렇지 않으면 분기된 그래프에서 기울기가 완전히 누적되기 전에 상위 노드의 backward가 실행되어 잘못된 미분값이 전파됩니다.

```python
def build_topological_order(root_tensor):
    order = []
    visited = set()
    
    def dfs(tensor):
        if tensor not in visited:
            visited.add(tensor)
            if tensor.creator is not None:
                # creator의 입력 텐서들을 먼저 재귀 방문
                for input_tensor in tensor.creator.inputs:
                    dfs(input_tensor)
            order.append(tensor)
            
    dfs(root_tensor)
    return order  # order[::-1] 순서로 backward 호출
```
- **시간 복잡도**: 노드 수 $V$, 에지 수 $E$에 대해 $\mathcal{O}(V + E)$
- **공간 복잡도**: 재귀 호출 스택 및 visited 집합 $\mathcal{O}(V)$

## 4. 역전파(Backpropagation) 수학적 유도

### 4.1 벡터 미적분학 기반 연쇄 법칙 (Multivariate Chain Rule)
스칼라 손실 함수 $L \in \mathbb{R}$과 벡터 변환 $y = f(x)$, $z = g(y)$ ($x \in \mathbb{R}^n, y \in \mathbb{R}^m, z \in \mathbb{R}^p$)에 대하여:
$$\frac{\partial L}{\partial x_i} = \sum_{j=1}^{m} \frac{\partial L}{\partial y_j} \frac{\partial y_j}{\partial x_i}$$

행렬 표기법으로 나타내면, 손실 $L$에 대한 그라디언트 행벡터는 야코비안 행렬(Jacobian Matrix) $J_{yx} = \left[ \frac{\partial y_j}{\partial x_i} \right] \in \mathbb{R}^{m \times n}$과 다음과 같은 **Vector-Jacobian Product (VJP)**를 이룹니다:
$$\nabla_x L = \nabla_y L \cdot J_{yx}$$

전치 그라디언트(열벡터 형태) 관점:
$$\left( \frac{\partial L}{\partial x} \right)^T = J_{yx}^T \left( \frac{\partial L}{\partial y} \right)^T$$

## 5. 핵심 레이어 Forward / Backward 완전 유도

### 5.1 Linear (Dense) Layer
입력 배치 $X \in \mathbb{R}^{N \times D_{in}}$, 가중치 $W \in \mathbb{R}^{D_{in} \times D_{out}}$, 편향 $b \in \mathbb{R}^{1 \times D_{out}}$, 출력 $Y \in \mathbb{R}^{N \times D_{out}}$:
$$Y = X W + \mathbf{1}_N b$$

손실 $L$로부터 상류 기울기 $\frac{\partial L}{\partial Y} \in \mathbb{R}^{N \times D_{out}}$이 주어졌을 때:
1. **입력에 대한 기울기 $\frac{\partial L}{\partial X}$**:
   $$\frac{\partial L}{\partial X} = \frac{\partial L}{\partial Y} W^T \quad \in \mathbb{R}^{N \times D_{in}}$$
2. **가중치에 대한 기울기 $\frac{\partial L}{\partial W}$**:
   $$\frac{\partial L}{\partial W} = X^T \frac{\partial L}{\partial Y} \quad \in \mathbb{R}^{D_{in} \times D_{out}}$$
3. **편향에 대한 기울기 $\frac{\partial L}{\partial b}$**:
   $$\frac{\partial L}{\partial b} = \sum_{i=1}^N \left( \frac{\partial L}{\partial Y} \right)_{i, :} = \mathbf{1}_N^T \frac{\partial L}{\partial Y} \quad \in \mathbb{R}^{1 \times D_{out}}$$

### 5.2 ReLU Layer
원소별(Element-wise) 연산:
$$y = \max(0, x)$$
도함수는 지시 함수(Indicator Function)로 표현:
$$\frac{\partial y}{\partial x} = \mathbb{I}(x > 0) = \begin{cases} 1 & \text{if } x > 0 \\ 0 & \text{if } x \le 0 \end{cases}$$
역전파 (Hadamard product):
$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \odot \mathbb{I}(x > 0)$$

### 5.3 Sigmoid Layer
$$y = \sigma(x) = \frac{1}{1 + e^{-x}}$$
도함수:
$$\frac{d \sigma(x)}{dx} = \frac{e^{-x}}{(1 + e^{-x})^2} = \frac{1}{1 + e^{-x}} \cdot \left( 1 - \frac{1}{1 + e^{-x}} \right) = \sigma(x)(1 - \sigma(x)) = y(1 - y)$$
역전파:
$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \odot (y \odot (1 - y))$$

### 5.4 Softmax + Categorical Cross-Entropy 결합 유도
로짓 벡터 $z \in \mathbb{R}^C$, 클래스 확률 $p_i = \frac{e^{z_i}}{\sum_{k=1}^C e^{z_k}}$, 원-핫 정답 벡터 $y \in \mathbb{R}^C$.
손실 함수:
$$L = -\sum_{k=1}^C y_k \ln p_k$$

로짓 $z_i$에 대한 $p_j$의 편미분:
$$\frac{\partial p_j}{\partial z_i} = \begin{cases} p_i (1 - p_i) & \text{if } i = j \\ -p_j p_i & \text{if } i \neq j \end{cases}$$

연쇄 법칙을 적용하여 $\frac{\partial L}{\partial z_i}$ 유도:
$$\begin{aligned}
\frac{\partial L}{\partial z_i} &= -\sum_{j=1}^C \frac{y_j}{p_j} \frac{\partial p_j}{\partial z_i} \\
&= -\frac{y_i}{p_i} p_i (1 - p_i) - \sum_{j \neq i} \frac{y_j}{p_j} (-p_j p_i) \\
&= -y_i (1 - p_i) + \sum_{j \neq i} y_j p_i \\
&= -y_i + y_i p_i + p_i \sum_{j \neq i} y_j \\
&= -y_i + p_i \left( y_i + \sum_{j \neq i} y_j \right)
\end{aligned}$$
원-핫 벡터의 특성상 $\sum_{j=1}^C y_j = 1$이므로:
$$\frac{\partial L}{\partial z_i} = p_i - y_i$$
배치 크기 $N$을 적용한 최종 행렬 형태:
$$\frac{\partial L}{\partial Z} = \frac{1}{N} (P - Y)$$

## 6. 가중치 초기화 이론 및 수학적 분산 보존 증명

선형 변환 $y = \sum_{i=1}^{n_{in}} w_i x_i$ ($b=0$)를 고려합니다. 가중치 $w_i$와 입력 $x_i$는 서로 독립이며, 평균이 0($\mathbb{E}[w_i] = 0, \mathbb{E}[x_i] = 0$)이라고 가정합니다.
$$\mathrm{Var}(y) = \sum_{i=1}^{n_{in}} \mathrm{Var}(w_i x_i) = \sum_{i=1}^{n_{in}} \left( \mathbb{E}[w_i^2]\mathbb{E}[x_i^2] - (\mathbb{E}[w_i]\mathbb{E}[x_i])^2 \right) = n_{in} \mathrm{Var}(w) \mathrm{Var}(x)$$

### 6.1 Zero Initialization (대칭성 깨기 실패 증명)
모든 가중치 $W_{ij}^{(l)} = 0$으로 초기화할 경우:
- 첫 번째 은닉층의 모든 뉴런 출력은 동일: $z_j^{(1)} = \sum_i 0 \cdot x_i + 0 = 0 \implies a_j^{(1)} = f(0)$.
- 역전파 시 각 가중치에 전파되는 기울기 $\frac{\partial L}{\partial W_{ij}^{(l)}}$ 역시 모든 $j$에 대해 완전히 동일해집니다.
- 파라미터 업데이트 후에도 $W_{i1}^{(l)} = W_{i2}^{(l)} = \dots = W_{ik}^{(l)}$가 영구히 유지되어, 실질적인 표현력이 1개의 뉴런으로 축퇴(Degeneration)됩니다.

### 6.2 Xavier (Glorot) Initialization (선형/Tanh 계열)
신호의 크기가 전방향(Forward) 및 역방향(Backward)으로 흐를 때 분산이 보존되어야 합니다:
- Forward 분산 보존 조건: $\mathrm{Var}(y) = \mathrm{Var}(x) \iff n_{in} \mathrm{Var}(w) = 1 \implies \mathrm{Var}(w) = \frac{1}{n_{in}}$
- Backward 분산 보존 조건: $\mathrm{Var}\left(\frac{\partial L}{\partial x}\right) = \mathrm{Var}\left(\frac{\partial L}{\partial y}\right) \iff n_{out} \mathrm{Var}(w) = 1 \implies \mathrm{Var}(w) = \frac{1}{n_{out}}$
- 입출력 차원이 다를 때 조화 평균(Harmonic Mean)을 취하여 절충:
  $$\mathrm{Var}(W) = \frac{2}{n_{in} + n_{out}}$$
- 균등분포 $U[-a, a]$의 분산은 $\frac{a^2}{3}$이므로:
  $$W \sim \mathcal{U}\left( -\sqrt{\frac{6}{n_{in} + n_{out}}}, \sqrt{\frac{6}{n_{in} + n_{out}}} \right), \quad W \sim \mathcal{N}\left( 0, \frac{2}{n_{in} + n_{out}} \right)$$

### 6.3 He (Kaiming) Initialization (ReLU 전용)
ReLU 함수 $f(x) = \max(0, x)$는 $x$가 0을 중심으로 대칭인 분포를 가질 때, 음수 영역의 신호를 0으로 절단합니다.
따라서 출력의 2차 모멘트(Moment)는 절반으로 감소합니다:
$$\mathbb{E}[y^2] = \frac{1}{2} n_{in} \mathrm{Var}(w) \mathbb{E}[x^2]$$
분산이 보존되기 위해서는 $\frac{1}{2} n_{in} \mathrm{Var}(w) = 1$이어야 합니다.
따라서:
$$\mathrm{Var}(W) = \frac{2}{n_{in}}$$
- 정규분포: $W \sim \mathcal{N}\left( 0, \sqrt{\frac{2}{n_{in}}} \right)$
- 균등분포: $W \sim \mathcal{U}\left( -\sqrt{\frac{6}{n_{in}}}, \sqrt{\frac{6}{n_{in}}} \right)$

## 7. 수치 미분 검증 (Gradient Checking) 알고리즘

해석적 미분(Analytical Gradient, $\nabla f_{ana}$)의 구현 정확성을 테일러 전개 기반 양방향 중심 차분(Centered Difference) 수치 미분($\nabla f_{num}$)으로 검증합니다.

### 7.1 테일러 전개와 중심 차분 오차 분석
$$f(\theta + \epsilon) = f(\theta) + f'(\theta)\epsilon + \frac{f''(\theta)}{2!}\epsilon^2 + \frac{f'''(\theta)}{3!}\epsilon^3 + \mathcal{O}(\epsilon^4)$$
$$f(\theta - \epsilon) = f(\theta) - f'(\theta)\epsilon + \frac{f''(\theta)}{2!}\epsilon^2 - \frac{f'''(\theta)}{3!}\epsilon^3 + \mathcal{O}(\epsilon^4)$$
두 식을 빼면:
$$f(\theta + \epsilon) - f(\theta - \epsilon) = 2 f'(\theta)\epsilon + \frac{2 f'''(\theta)}{6}\epsilon^3 + \mathcal{O}(\epsilon^5)$$
$$\frac{f(\theta + \epsilon) - f(\theta - \epsilon)}{2\epsilon} = f'(\theta) + \mathcal{O}(\epsilon^2)$$
중심 차분의 절단 오차(Truncation Error)는 단방향 차분($\mathcal{O}(\epsilon)$)보다 훨씬 정밀한 $\mathcal{O}(\epsilon^2)$ 수렴률을 갖습니다.

### 7.2 상대 오차(Relative Error) 척도 및 판정 기준
파라미터 벡터 크기에 따른 왜곡을 방지하기 위해 L2 정규화 기반 상대 오차를 측정합니다:
$$\text{Relative Error} = \frac{\| \nabla f_{ana} - \nabla f_{num} \|_2}{\| \nabla f_{ana} \|_2 + \| \nabla f_{num} \|_2 + 10^{-15}}$$

- $\text{Relative Error} \le 10^{-7}$: **통과(Pass)**, 수학적 구현 완벽
- $10^{-7} < \text{Relative Error} \le 10^{-4}$: 의심 (부동소수점 Float32 정밀도 한계 또는 국소 비선형 kink(ReLU 0 지점) 영향 확인 필요)
- $\text{Relative Error} > 10^{-4}$: **실패(Fail)**, 역전파 미분 공식 또는 전치(Transpose) 행렬 인덱스 버그 존재

## 8. XOR 문제와 선형 분리 불가능성 증명

### 8.1 단층 퍼셉트론(Single-Layer Perceptron)의 한계
XOR 진리표: $X = \{(0,0), (0,1), (1,0), (1,1)\}$, $Y = \{0, 1, 1, 0\}$.
단층 결정 경계: $w_1 x_1 + w_2 x_2 + b = 0$.
분리 조건 만족을 위한 연립 부등식:
$$\begin{cases}
(0,0): & b < 0 \\
(0,1): & w_2 + b \ge 0 \\
(1,0): & w_1 + b \ge 0 \\
(1,1): & w_1 + w_2 + b < 0
\end{cases}$$
(2)번 식과 (3)번 식을 더하면: $w_1 + w_2 + 2b \ge 0$.
여기에 (1)번 식의 $b < 0$을 대입하면 $w_1 + w_2 + b > w_1 + w_2 + 2b \ge 0 \implies w_1 + w_2 + b > 0$.
이는 (4)번 식 $w_1 + w_2 + b < 0$과 명백한 모순(Contradiction)을 일으킵니다. 따라서 단층 선형 분리는 수학적으로 불가능합니다.

### 8.2 2층 퍼셉트론에 의한 매니폴드 변환
2개의 은닉 뉴런 $h_1 = \text{ReLU}(x_1 - x_2)$, $h_2 = \text{ReLU}(x_2 - x_1)$을 도입하면:
- $(0,0) \to (0, 0)$
- $(0,1) \to (0, 1)$
- $(1,0) \to (1, 0)$
- $(1,1) \to (0, 0)$
입력 공간에서는 얽혀 있던 점들이 은닉 특징 공간 $(h_1, h_2)$에서는 $(0,0)$에 클래스 0이 모이고, $(0,1)$과 $(1,0)$에 클래스 1이 배치되어 단일 초평면 $h_1 + h_2 - 0.5 = 0$으로 완전 선형 분리가 가능해집니다.

## 9. MNIST 분류기 아키텍처 및 미니 딥러닝 프레임워크 설계

### 9.1 파이프라인 데이터 흐름
$$\underbrace{X}_{\mathbb{R}^{B \times 784}} \xrightarrow{W_1, b_1} \underbrace{Z_1}_{\mathbb{R}^{B \times 128}} \xrightarrow{\text{ReLU}} \underbrace{A_1}_{\mathbb{R}^{B \times 128}} \xrightarrow{W_2, b_2} \underbrace{Z_2}_{\mathbb{R}^{B \times 10}} \xrightarrow{\text{SoftmaxCE}(Y)} \underbrace{\mathcal{L}}_{\mathbb{R}}$$

### 9.2 프레임워크 학습 루프 슈도코드
```python
# 1. 하이퍼파라미터 및 모델 초기화
lr = 0.01
batch_size = 64
epochs = 10

W1 = np.random.randn(784, 128) * np.sqrt(2.0 / 784)  # He 초기화
b1 = np.zeros((1, 128))
W2 = np.random.randn(128, 10) * np.sqrt(2.0 / 128)
b2 = np.zeros((1, 10))

# 2. 미니배치 SGD 학습 루프
for epoch in range(epochs):
    indices = np.random.permutation(len(X_train))
    for i in range(0, len(X_train), batch_size):
        batch_idx = indices[i:i + batch_size]
        xb, yb = X_train[batch_idx], Y_train[batch_idx]
        
        # [Forward Pass]
        z1 = np.dot(xb, W1) + b1
        a1 = np.maximum(0, z1)
        z2 = np.dot(a1, W2) + b2
        
        # Softmax 수치 안정성 (Log-Sum-Exp 트릭)
        exp_z2 = np.exp(z2 - np.max(z2, axis=1, keepdims=True))
        probs = exp_z2 / np.sum(exp_z2, axis=1, keepdims=True)
        loss = -np.mean(np.log(probs[np.arange(len(yb)), yb] + 1e-12))
        
        # [Backward Pass]
        dz2 = probs.copy()
        dz2[np.arange(len(yb)), yb] -= 1.0
        dz2 /= len(yb)
        
        dW2 = np.dot(a1.T, dz2)
        db2 = np.sum(dz2, axis=0, keepdims=True)
        
        da1 = np.dot(dz2, W2.T)
        dz1 = da1 * (z1 > 0)
        
        dW1 = np.dot(xb.T, dz1)
        db1 = np.sum(dz1, axis=0, keepdims=True)
        
        # [Gradient Update]
        W2 -= lr * dW2
        b2 -= lr * db2
        W1 -= lr * dW1
        b1 -= lr * db1
```
- **시간 복잡도**: 에폭당 배치 루프 $\mathcal{O}\left( \frac{N}{B} \cdot (B \cdot D_{in} \cdot D_h + B \cdot D_h \cdot D_{out}) \right) = \mathcal{O}(N \cdot D_h(D_{in} + D_{out}))$
- **공간 복잡도**: 순전파 활성화 캐시 및 가중치 행렬 $\mathcal{O}(D_{in}D_h + D_hD_{out} + B(D_{in} + D_h + D_{out}))$

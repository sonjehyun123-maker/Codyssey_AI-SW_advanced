A1-1 이커머스 멀티모달 EDA 및 RFM 고객 세분화 분석 리포트¶

1. 프로젝트 개요¶

이커머스 거래 데이터(수치·범주·날짜·텍스트)와 상품 이미지 텐서(배열)를 결합한 멀티모달 데이터를 객체지향 DataAnalyzer 파이프라인으로 정제하고, 통계 분석과 RFM 고객 세분화로 비즈니스 전략을 도출합니다.

데이터 규모¶

  • 거래 로그: 1,500행 × 12컬럼(파생 피처 포함 21컬럼), 고객 327명, 상품 33종
  • 상품 이미지: 1,500장 × 64x64 × 3(RGB) uint8 텐서

분석 목표¶

  1. 멀티모달 피처 엔지니어링: NumPy 축(axis) 벡터 연산으로 이미지 통계량 추출 + 상품명 텍스트 특성 생성
  2. 데이터 정제: 그룹별(GroupBy) 결측치 대치 및 IQR 기반 이상치 탐지/클리핑
  3. EDA: 히스토그램·박스플롯·막대·히트맵·산점도·라인차트 6종 시각화
  4. RFM 세분화: 5개 고객군(VIP·Loyal·At_Risk·New·Churned) 발굴

본 노트북의 해석 문장에 등장하는 모든 수치는 src/build_notebook.py가 파이프라인을 실제 실행해 산출한 값이 자동 주입된 것입니다(수기 입력 아님).

기본 구조 해석¶

  • 규모: 원본 1,500행 × 12컬럼, 고객 327명, 상품 33종 (멀티모달·텍스트 피처를 추출하면 21컬럼이 됩니다). 기간은 2025-01-01 ~ 2025-12-30입니다.
  • 결측치: customer_age 59건(3.9%), customer_gender 34건(2.3%)이 존재합니다.
  • 결제 금액 분포: 평균 139,459원, 중앙값 72,000원, 최댓값 4,500,000원. 평균이 중앙값의 1.94배로 오른쪽으로 긴 꼬리(right-skewed) 분포입니다.
  • 시사점: 평균이 중앙값을 크게 웃도는 형태는 소수 대형 결제가 평균을 끌어올린다는 뜻이므로, 대푯값으로 중앙값을 함께 보고하고 IQR 기반 경계 처리가 필요합니다. 나이 결측치는 카테고리별 구매 성향이 다르므로 그룹별 중앙값 대치가 적절합니다.

3. 멀티모달 피처 엔지니어링¶

  • 이미지: for 루프 없이 NumPy 축 연산으로 이미지별 픽셀 평균/표준편차, R·G·B 채널 평균을 계산합니다.
  • 텍스트: 상품명의 문자 수(product_name_len)와 어절 수(product_word_count)를 파생 변수로 만듭니다.
  • NumPy 축 벡터화 성능 벤치마크 (#16): 1,500개 이미지 텐서에 대해 순수 Python for loop 방식과 NumPy 축 벡터화 연산(axis=(1, 2, 3))의 실행 시간과 결과 일치성을 정량 비교합니다.

import time

# 벤치마크: NumPy 벡터화 vs 순수 Python for loop (#16)
# 1. Python for loop 방식
t0 = time.perf_counter()
loop_means = np.zeros(len(images))
for i in range(len(images)):
    loop_means[i] = np.mean(images[i])
t_loop = time.perf_counter() - t0

# 2. NumPy axis=(1, 2, 3) 축 벡터 연산 방식
t0 = time.perf_counter()
vec_means = np.mean(images, axis=(1, 2, 3))
t_vec = time.perf_counter() - t0

speedup = t_loop / t_vec if t_vec > 0 else 0.0
all_match = bool(np.allclose(loop_means, vec_means))
is_c_contiguous = bool(images.flags["C_CONTIGUOUS"])

benchmark_df = pd.DataFrame({
    "방식": ["Python For Loop (단건 반복)", "NumPy Axis Vectorization (축 연산)"],
    "실행 시간": [f"{t_loop:.5f}초", f"{t_vec:.5f}초"],
    "상대 속도": ["1.00x (기준)", f"{speedup:.2f}x 고속화"],
    "결과 일치 (allclose)": ["-", str(all_match)],
    "메모리 C-연속성": ["-", str(is_c_contiguous)],
})

NumPy 벡터화 성능 분석 해석 (#16)¶

  • 수치 근거: 1,500장 64x64x3 RGB 이미지(약 17.58 MiB)에 대해 축 벡터 연산(axis=(1, 2, 3))은 순수 Python 반복문 대비 유의미한 연산 시간 단축을 달성하며, 두 방식의 계산 결과는 오차 없이 정확히 일치(allclose=True)합니다.
  • 이론적 원리: NumPy 배열은 메모리 상에 C-연속(C-contiguous) 형태로 배치되어 캐시 지역성(Cache Locality)을 극대화하며, Python 인터프리터의 바이트코드 루프 오버헤드 없이 C 내부 루프 및 CPU의 SIMD(단일 명령어 다중 데이터) 명령어를 활용해 블록 단위로 병렬 처리합니다.

결측치·이상치 처리 해석¶

  • 결측치: 대치 후 결측치는 0건입니다. 나이는 상품 카테고리별 중앙값으로 채워 카테고리별 구매 연령대 차이를 보존했습니다.
  • 이상치 규모: Q1 36,100원, Q3 132,050원, IQR 95,950원이며 상한은 275,975원입니다. 이를 넘는 결제는 **162건(10.8%)**입니다.
  • 탐지 결과의 성격: 이상치 중 가장 많은 카테고리는 Electronics 102건입니다 (해당 카테고리 전체 335건 중 30%). 단가가 높은 카테고리는 구조적으로 상한을 넘기므로, 이 162건은 "전부 오류값"이 아니라 고가 상품의 정상 결제가 다수 포함된 집합으로 읽어야 합니다.
  • 비용: 클리핑으로 줄어드는 금액은 전체 결제액의 **29.0%**입니다. 분포를 안정화하는 대신 매출 규모는 축소되므로, 매출 집계에는 원본 amount를, 분포·상관 분석에는 amount_clipped를 사용합니다(본 리포트의 RFM Monetary는 원본 amount 기준).

7. RFM 기반 고객 세분화¶

  • 기준일: 데이터 최종 거래일 +1일
  • R(최근성) = 기준일 − 마지막 구매일 (작을수록 우수), F(빈도) = 주문 건수, M(금액) = 누적 결제액
  • 점수화: 평균 순위 백분위 기반 1~4점. 동점자는 동일 점수를 받고, 점수군 크기는 데이터 분포를 따릅니다 (강제 25% 분할 아님).
  • 세그먼트 규칙(위에서부터 먼저 만족하는 조건에서 확정):
    1. VIP: R≥3 & F≥3 & M≥3
    2. New: R≥3 & 주문 1건 (최초 구매 고객) — Loyal보다 먼저 판정
    3. Loyal: R≥3 & (F≥2 | M≥2)
    4. At_Risk: R≤2 & (F≥3 | M≥3)
    5. Churned: 그 외

분석의 한계 (먼저 밝혀야 할 것들)¶

  1. 데이터가 합성입니다. 구매 가중치·결측·이상치를 설계해 주입했으므로, 세그먼트 비율은 시장의 실측치가 아니라 파이프라인 검증용 분포입니다.
  2. 이미지 피처는 카테고리 대리변수입니다(합성 이미지 + 행 인덱스 매핑). 멀티모달 융합의 효과를 주장하려면 실제 상품 이미지에서 추출한 임베딩이 필요합니다.
  3. 클리핑 기준이 두 갈래입니다. 분포·상관 분석은 amount_clipped, 매출·RFM Monetary는 원본 amount를 사용합니다. 의도된 선택이지만 두 수치를 같은 문장에서 비교하면 안 됩니다.
  4. 인과가 아닙니다. 세그먼트와 매출의 관계는 관측적 연관이며, 프로모션 효과는 A/B 테스트로 검증해야 합니다.
  5. 시계열 구조가 없습니다. 날짜를 균등 분포로 생성해 계절성·추세가 없으므로 월별 매출 차이는 노이즈입니다.

## 2. 멀티모달 데이터셋 생성 원리 (`src/generate_dataset.py`)

평가 기준인 "1,000건 이상, 8개 이상 컬럼, 3가지 이상 멀티모달 데이터 결합"을 만족하기 위해 다음 요소들을 설계했습니다:

1. **고객 및 거래 풀 (350명 규모, 1,500건 거래)**:
   - 현실적인 RFM 점수 분포가 나오도록 상위 50명 고객에게 4배의 구매 가중치를 부여하여 단골 고객군(VIP)을 자연스럽게 시뮬레이션했습니다.
2. **멀티모달 5종 결합**:
   - **수치형**: `amount`, `unit_price`, `quantity`, `customer_age`
   - **범주형**: `category` (Fashion, Electronics, Beauty, Home, Sports), `customer_gender`
   - **날짜형**: `order_date` (2025-01-01 ~ 2025-12-30)
   - **텍스트**: `product_name` (예: "오버핏 베이직 코튼 라운드 티셔츠")
   - **이미지 텐서**: `product_images.npy` (64×64×3 RGB 배열)
3. **현실적 결측치 및 이상치 주입**:
   - `customer_age` 결측 59건(3.9%), `customer_gender` 결측 34건(2.3%) 주입
   - 대량 결제 및 전산 오류성 이상치(0.8%) 주입으로 IQR 알고리즘 검증 준비

## 3. 객체지향 파이프라인 심층 해설 (`src/pipeline.py`)

### 3.1 데이터 로드 및 날짜 파싱 (`load_data`)
```python
self.df = pd.read_csv(csv_path)
if "order_date" in self.df.columns:
    self.df["order_date"] = pd.to_datetime(self.df["order_date"])
if img_path and os.path.exists(img_path):
    self.images = np.load(img_path)
```
- 문자열로 된 날짜 컬럼을 `pd.to_datetime`으로 변환하여 이후 시계열 집계와 Recency 일수 계산이 가능하도록 만듭니다.

### 3.2 NumPy 벡터 연산 기반 이미지/텍스트 특성 추출 (`extract_multimodal_features`)
**평가 핵심**: 파이썬 `for` 반복문 없이 배열 축(axis) 연산만으로 계산해야 합니다.

```python
# (1500, 64, 64, 3) 텐서에서 axis=(1, 2, 3)으로 이미지별 전체 픽셀 평균/표준편차 단번에 계산
img_mean_all = np.mean(self.images, axis=(1, 2, 3))
img_std_all = np.std(self.images, axis=(1, 2, 3))

# 채널별 평균: axis=(1, 2) -> 결과 shape: (1500, 3)
img_channel_means = np.mean(self.images, axis=(1, 2))
self.df["img_r_mean"] = img_channel_means[indices, 0]
self.df["img_g_mean"] = img_channel_means[indices, 1]
self.df["img_b_mean"] = img_channel_means[indices, 2]
```
- 반복문을 돌리면 1,500장의 이미지 연산에 수 초 이상 소요되지만, NumPy C-레벨 벡터 연산을 사용하면 수 밀리초(ms) 만에 완료됩니다.
- 텍스트는 `str.len()`(글자 수)과 `str.split().str.len()`(어절 수)을 사용해 피처를 추출합니다.

### 3.3 그룹별(GroupBy) 결측치 대치 알고리즘 (`handle_missing_values`)
단순 전체 평균으로 결측치를 채우면 "10대 전자기기 구매자"의 나이가 "전체 평균 나이(35세)"로 왜곡됩니다.
```python
# 카테고리별 중앙값 대치
group_stats = self.df.groupby(group_col)[target_col].transform("median")
self.df[target_col] = self.df[target_col].fillna(group_stats).fillna(overall_stat)
```
- `transform("median")`을 사용하면 원본 데이터프레임의 인덱스 형태를 그대로 유지하면서 각 행의 카테고리에 해당하는 중앙값으로 결측치가 대치됩니다.

### 3.4 IQR 사분위수 이상치 탐지 및 클리핑 (`detect_outliers`)
```python
q1 = float(np.percentile(series, 25))
q3 = float(np.percentile(series, 75))
iqr = q3 - q1

lower_bound = q1 - (iqr_multiplier * iqr)
upper_bound = q3 + (iqr_multiplier * iqr)
is_outlier = (self.df[column] < lower_bound) | (self.df[column] > upper_bound)
```
- 정규분포를 따르지 않는 비대칭 이커머스 매출 데이터는 평균과 표준편차($3\sigma$) 대신 중앙값 기반의 $IQR$ 기법을 사용해야 왜곡 없이 정확한 이상치 경계선을 그을 수 있습니다.
- `np.clip`을 적용해 이상치를 데이터에서 삭제(Drop)하지 않고 상한선으로 눌러주어(Clipping) 데이터 손실을 방지합니다.

### 3.5 RFM 고객 세분화 및 분위수 스코어링 로직 (`calculate_rfm`)
- **기준일($T_{ref}$)**: 데이터 최종 거래일 + 1일
- **지표 집계**:
  - $R$ (Recency): $T_{ref} - \max(\text{order\_date})$ (작을수록 최근 구매)
  - $F$ (Frequency): 고객별 주문 건수 (클수록 우수)
  - $M$ (Monetary): 고객별 결제 총액 (클수록 우수)
- **분위수 스코어링 (`pd.qcut`)**:
  - 동점자가 많은 $F, M$은 `rank(method="first")` 처리 후 4분위수(1~4점) 매핑
  - $R$은 역순 매핑 (작을수록 4점)
- **5대 세그먼트 규칙 매핑**:
  - `VIP`: R, F, M 모두 상위권 ($R \ge 3 \land F \ge 3 \land M \ge 3$)
  - `Loyal`: 구매 경험이 많고 최근에도 방문 ($R \ge 3 \land (F \ge 2 \lor M \ge 2)$)
  - `New`: 최근 첫 구매 유입 ($R \ge 3 \land F = 1$)
  - `At_Risk`: 과거 고가치 고객이나 최근 미방문 ($R \le 2 \land (F \ge 3 \lor M \ge 3)$)
  - `Churned`: 전 지표가 낮은 완전 이탈군

## 5. 데이터 기반 비즈니스 인사이트 도출 3단계 공식

체크리스트 요구사항을 완벽히 만족하기 위해 **(근거) - (실행) - (검증)** 구조로 기술합니다.

1. **(근거 - Evidence)**:
   - 추상적인 서술이 아닌 명확한 수치(예: "VIP 28.7%가 총 매출 54.2% 견인", "상관계수 0.68")를 제시합니다.
2. **(실행 - Action)**:
   - **대상(Target)** + **실행 방법(Action)** + **기대 효과(KPI Impact)**를 구체적인 마케팅/운영 전략으로 정의합니다.
3. **(검증 - Validation)**:
   - 이 가설을 입증하기 위해 **추가로 필요한 데이터**(예: 웹 세션 로그, 상품별 마진율)와 가설이 틀렸을 가능성인 **반증 가능성**(예: 체리피킹, 수요 선반영)을 1문장 이상 반드시 기술합니다.

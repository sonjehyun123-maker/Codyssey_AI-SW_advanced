## 1. NumPy 벡터 연산 (Vectorization)
- **개념**: 배열의 각 원소에 대한 반복문(`for`)을 C 레벨의 연속된 메모리 공간에서 단일 명령어로 일괄 처리하는 연산 기법.
- **Python 반복문 vs 벡터 연산**:
  - Python `for`문: 각 반복마다 동적 타입 체크와 객체 디레퍼런싱 오버헤드로 인해 속도가 매우 느림.
  - NumPy 벡터화: SIMD(Single Instruction Multiple Data) 하드웨어 가속을 활용해 수십~수백 배 빠른 속도 제공.
- **브로드캐스팅(Broadcasting)**: 형상(Shape)이 다른 배열 간의 산술 연산 시, 작은 배열을 자동으로 확장하여 크기를 맞추는 메커니즘.

---

## 2. 멀티모달 데이터(Multimodal Data)의 이해
- **이커머스 데이터의 복합 유형**:
  - 수치형(Numerical): 가격, 수량, 할인율 (스케일링 및 통계 분석)
  - 범주형(Categorical): 카테고리, 결제 수단 (원-핫 인코딩, 레이블 인코딩)
  - 날짜형(Datetime): 주문일시, 가입일자 (요일, 월, 최근성 계산)
  - 이미지 배열(Image Array): 상품 썸네일 (픽셀 평균, 표준편차 등 통계적 특성 벡터 추출)
- **객체 지향 파이프라인(OOP Pipeline)**:
  - 단일 스크립트가 아닌 `class DataPipeline` 내부에 `fit()`, `transform()`, `extract_features()` 메서드로 분리하여 재사용성과 유지보수성 극대화.

## 3. 이상치 탐지 및 결측치 처리
### 3.1 IQR(Interquartile Range) 방식
- 데이터의 중간 50% 범위를 기준으로 이상치를 판정하는 대표적인 비모수적 기법.
- $Q_1$: 제1사분위수 (25%), $Q_3$: 제3사분위수 (75%)
- $IQR = Q_3 - Q_1$
- **정상 범위**:
  $$[Q_1 - 1.5 	imes IQR, \quad Q_3 + 1.5 	imes IQR]$$
- 정상 범위를 벗어나는 데이터는 이상치로 분류하여 제거 또는 클리핑(Clipping/Winsorizing) 처리.

### 3.2 그룹별 결측치 대치
- 전체 평균으로 단순 대치할 경우 집단 간 고유 특성이 왜곡됨.
- 예: 카테고리별 상품 가격의 평균/중앙값으로 그룹별 세부 대치 수행.

## 4. RFM 고객 세분화 분석
- 고객의 과거 거래 데이터를 바탕으로 고객 가치를 정량 평가하는 마케팅 프레임워크.
  - **R (Recency)**: 가장 최근 구매일로부터 경과한 일수 (작을수록 고점수)
  - **F (Frequency)**: 특정 기간 내 구매 횟수 (많을수록 고점수)
  - **M (Monetary)**: 특정 기간 내 총 구매 금액 (클수록 고점수)
- **세그먼트 분류**:
  1. **VIP / Champions**: R, F, M 모두 최상위. 로열티 프로그램 및 VIP 전용 혜택 제공.
  2. **Loyal Customers**: 꾸준히 구매하지만 객단가가 중간 수준인 고객. 업셀링(Up-selling) 전략.
  3. **At-Risk / 이탈 우려**: 구매 빈도와 금액이 높았으나 최근 구매가 뜸한 고객. 재방문 할인 쿠폰 및 리인게이지먼트 마케팅.
  4. **Lost / 이탈 고객**: 최근 구매일이 오래되고 빈도/금액도 낮은 고객. 저비용 알림 전략.

## 1. 데이터 분석의 개념과 전체 흐름
데이터 분석은 요리에 비유할 수 있습니다. 마트에서 사 온 날것의 재료를 바로 냄비에 넣으면 모래가 씹히거나 맛이 없겠죠? 
- **EDA (탐색적 데이터 분석, Exploratory Data Analysis)**: 냉장고에 어떤 재료가 있고 상태가 신선한지 이리저리 냄새 맡고 살펴보는 단계입니다. 데이터의 크기, 평균적인 값, 이상한 값은 없는지 눈으로 확인합니다.
- **데이터 전처리 (Preprocessing)**: 재료를 물에 씻고, 껍질을 벗기고, 상한 부분을 도려내는 작업입니다. 비어 있는 칸을 채우고, 말도 안 되는 오타나 오류 값을 정상으로 바로잡습니다.
- **파이프라인 (Pipeline)**: 매번 요리할 때마다 번거롭게 채칼을 찾고 도마를 씻는 대신, "재료 투입 $\rightarrow$ 세척 $\rightarrow$ 썰기 $\rightarrow$ 포장"이 한 번에 자동으로 돌아가는 자동 요리 로봇 시스템을 구축하는 것입니다.

## 2. 파이썬 넘파이(NumPy)의 마법: 벡터화와 브로드캐스팅
엑셀 시트에 100만 명의 결제 금액이 적혀 있는데, 모든 고객에게 10% 할인을 적용해야 한다고 상상해 보세요.
- **일반적인 반복문 (For loop)**: 한 사람씩 이름을 부르며 계산기를 100만 번 두드리는 방식입니다. 너무 느리고 손가락이 아픕니다.
- **벡터화 (Vectorization)**: 100만 명의 장부를 거대한 마법 상자에 넣고, "동시에 전부 0.9를 곱해라!" 하고 주문을 한 번만 외치는 방식입니다. 컴퓨터의 뇌(CPU)가 한 번에 여러 계산을 번개처럼 처리합니다.
- **브로드캐스팅 (Broadcasting)**: 크기가 다른 데이터끼리도 알아서 척척 크기를 맞춰주는 자동 늘리기 기능입니다. 예를 들어 100만 명의 장부 행렬에 숫자 딱 하나인 `0.9`를 곱하려고 할 때, 컴퓨터가 알아서 0.9를 100만 개로 쫙 복사해서 맞춰줍니다.

## 3. 멀티모달 데이터: 오감으로 손님 파악하기
쇼핑몰 손님을 제대로 알려면 한 가지 정보만 봐서는 부족합니다. 여러 감각(멀티모달)을 동원해야 합니다.
1. **수치형 데이터 (Numbers)**: 나이, 장바구니에 담은 개수, 총 결제 금액 등 숫자로 측정되는 데이터입니다.
2. **범주형 데이터 (Categories)**: 회원 등급(골드/실버/브론즈), 성별, 선호 카테고리(의류/가전) 등 종류나 그룹을 나타냅니다.

## 4. 객체지향(OOP) 파이프라인: 나만의 전처리 요리 로봇 만들기
데이터를 분석할 때마다 코드를 복사해서 붙여넣으면 나중에 버그가 발생했을 때 어디가 틀렸는지 찾기 어렵습니다. 그래서 우리는 **레고 블록(Class)** 형태로 전처리 도구를 만듭니다.
- **`fit` (배우기/익히기)**: 훈련용 데이터의 기준(예: 평균값, 최고값)을 기억하고 학습합니다.
- **`transform` (변환하기)**: `fit`에서 배운 기준을 가지고 실제 데이터를 규격에 맞게 깎고 다듬습니다.
- **`fit_transform` (배우고 바로 변환하기)**: 처음 데이터를 넣어 기준도 배우고 변환까지 일사천리로 끝내는 기능입니다.

## 5. IQR 이상치 탐지: 튀는 값 걸러내기
운동장에서 100명이 달리기를 하는데, 99명은 15초 안팎으로 들어왔는데 한 사람이 0.1초 만에 들어왔거나 5시간 만에 들어왔다면 시스템 오류이거나 거짓말일 가능성이 큽니다.
- **중간 50%의 범위 (IQR)**: 학생들을 성적순으로 1등부터 100등까지 줄 세웠을 때, 25등(Q1)부터 75등(Q3)까지의 구간 길이를 IQR이라고 부릅니다.
- **정상 울타리**: 25등 점수보다 IQR의 1.5배만큼 아래로 떨어지거나, 75등 점수보다 1.5배 넘게 훌쩍 뛰어넘는 값은 "비정상적으로 튀는 값(이상치)"으로 보고 깃발을 꽂습니다.

## 8. RFM 분석: 쇼핑몰의 찐단골 찾기
누가 우리 가게의 최고 손님일까요? 세 가지 질문을 던집니다.
1. **R (Recency, 최근성)**: "가장 최근에 언제 방문했나요?" (어제 온 손님이 1년 전에 온 손님보다 중요!)
2. **F (Frequency, 빈도)**: "얼마나 자주 샀나요?" (한 달에 10번 온 손님이 1번 온 손님보다 중요!)
3. **M (Monetary, 금액)**: "총 얼마를 썼나요?" (100만 원 쓴 손님이 1만 원 쓴 손님보다 중요!)

**고객 등급 4가지 세그먼트 예시:**
- 👑 **VIP 챔피언 (최고 충성 고객)**: 최근에도 왔고, 자주 오고, 돈도 많이 씀 $\rightarrow$ 특별 선물과 전담 혜택 제공!
- 💖 **충성 단골**: 자주 사고 돈도 제법 쓰지만, 최근 며칠 뜸함 $\rightarrow$ 신상품 추천 알림 발송!
- ⚠️ **이탈 우려 고객**: 예전엔 큰돈 쓰고 자주 왔는데 최근 몇 달간 발길을 뚝 끊음 $\rightarrow$ "보고 싶었어요" 파격 할인 쿠폰 지급!
- 🌱 **새싹 신규 고객**: 최근에 처음 가입해서 첫 구매를 완료함 $\rightarrow$ 재구매 유도 웰컴 패키지 제공!

## 1. 데이터 분석 파이프라인 아키텍처 및 무결성 보장
프로덕션 레벨 데이터 파이프라인의 핵심은 **Data Leakage(데이터 누수) 방지**와 **재현성(Reproducibility)**에 있습니다.
데이터 파이프라인은 원천 소스(Raw Transactional DB, S3 Object Storage)로부터 데이터를 인출하여 피처 엔지니어링을 거쳐 추론 및 통계 모델링 모듈로 전달되는 유향 비순환 그래프(DAG, Directed Acyclic Graph) 구조를 가집니다.

```
[Raw Multimodal Data] 
       │
       ▼
[Train / Test Split]  ──(Data Leakage 차단 분기점)
       │
       ├─────────────────────────────────┐
       ▼ (Train Fit)                     ▼ (Test Transform Only)
[Imputer & Scaler Pipeline] ──────> [Transformed Evaluation Set]
       │
       ▼
[RFM Feature Extraction & Quantile Binning]
       │
       ▼
[Clustering / Segment Classification]
```

- **Data Leakage**: 전처리 단계에서 Test 데이터의 통계량(평균, 분산, 사분위수 등)이 Train 단계의 Transformer에 포함되면 모델 성능이 비정상적으로 과대평가되는 일반화 오류가 발생합니다. 반드시 Train 셋에서만 파라미터를 추정(`fit`)하고, Test 셋은 추정된 파라미터를 적용(`transform`)만 해야 합니다.

## 2. NumPy 벡터 연산 최적화: Vectorization & Memory Layout
파이썬의 기본 리스트 연산은 포인터 참조 오버헤드, 동적 타입 디스패칭(Dynamic Type Dispatching), GIL(Global Interpreter Lock)로 인해 $O(N)$의 인터프리터 오버헤드가 발생합니다. 반면 NumPy `ndarray`는 C-레벨 연속 메모리 버퍼(Contiguous Memory Buffer)를 사용하여 성능을 극대화합니다.

### 2.1 메모리 레이아웃과 SIMD
NumPy 배열은 연속된 메모리 주소 상에 고정 크기 데이터 타입(e.g., `float64`, `int32`)으로 배치됩니다.
- CPU의 **SIMD (Single Instruction, Multiple Data)** 명령어 집합(AVX-512, NEON 등)을 활용하여 단일 클럭 사이클에 복수의 데이터 벡터를 병렬로 연산합니다.
- **Cache Locality**: 공간적 지역성(Spatial Locality)을 극대화하여 L1/L2 캐시 미스(Cache Miss) 레이턴시를 최소화합니다.

### 2.2 브로드캐스팅(Broadcasting)의 수학적 규칙
두 배열 $A$, $B$의 shape가 각각 $(d_{A,1}, d_{A,2}, \dots, d_{A,n})$, $(d_{B,1}, d_{B,2}, \dots, d_{B,m})$일 때:
1. 차원 수가 다르면 차원이 작은 배열의 앞쪽(왼쪽)에 차원 1을 패딩하여 길이를 일치시킵니다.
2. 각 축(axis)에 대해 두 배열의 차원 길이가 동일하거나, 둘 중 하나의 차원 길이가 1이어야 연산이 가능합니다.
3. 차원 길이가 1인 축은 상대 배열의 차원 크기에 맞추어 가상 복제(Stride 0 스트라이드 테크닉)되어 메모리 복사 없이 메모리 포인터 이동만으로 확장 연산됩니다.

```python
# Strides를 이용한 효율적 메모리 뷰
import numpy as np
A = np.array([[1.0], [2.0], [3.0]]) # shape (3, 1)
B = np.array([10.0, 20.0])          # shape (2,) -> 가상 (1, 2)
# 브로드캐스팅 결과 shape: (3, 2), 메모리 재할당 없이 SIMD 브로드캐스팅 연산
C = A + B 
```

## 3. 멀티모달(Multimodal) 데이터 스키마 및 텐서 변환
이커머스 분석 환경에서 멀티모달 데이터는 이종(Heterogeneous) 형태의 특징 공간을 가집니다.

| 모달리티 | 원천 형태 | 표현 공간 / 내부 구조 | 전처리 및 임베딩 파이프라인 |
| :--- | :--- | :--- | :--- |
| **수치형 (Tabular)** | Float, Int | $\mathbb{R}^k$ 실수 공간 | 결측치 대치, Robust / Quantile 정규화 |
| **범주형 (Tabular)** | String, Code | 이산 심볼 집합 $\Sigma$ | Target Encoding, One-Hot Encoding, Embedding |
| **시간형 (Temporal)**| ISO 8601 Timestamp | Unix Epoch Float / 계절 주기 | Cyclical Encoding: $\sin(\frac{2\pi t}{T}), \cos(\frac{2\pi t}{T})$ |
| **비전 (Image)** | JPEG / PNG Raster | 텐서 $\mathbf{X} \in \mathbb{R}^{H \times W \times C}$ | Resizing, Normalization, CNN/ViT Feature Vector $\mathbf{z} \in \mathbb{R}^d$ |

다양한 모달리티로부터 추출된 벡터들은 후기 융합(Late Fusion) 또는 조기 융합(Early Fusion, Concatenation: $\mathbf{x}_{\text{fused}} = [\mathbf{x}_{\text{num}} \,\|\, \mathbf{x}_{\text{cat}} \,\|\, \mathbf{x}_{\text{img}}]$)을 통해 통합 고객 벡터를 구성합니다.

## 4. 객체지향(OOP) Transformer 설계 패턴
Scikit-Learn의 Estimator/Transformer API 규약을 준수하는 사용자 정의 모듈을 구현합니다. 이는 파이프라인 내에서 상태(State, 예: 학습 데이터의 통계값)와 행위(Behavior, 변환 로직)를 엄격히 캡슐화합니다.

```python
from sklearn.base import BaseEstimator, TransformerMixin
import pandas as pd
import numpy as np

class GroupwiseMedianImputer(BaseEstimator, TransformerMixin):
    """
    특정 범주형 그룹 변수에 기반하여 수치형 변수의 결측치를 조건부 중위수로 대치하는 변환기
    """
    def __init__(self, group_col: str, target_col: str):
        self.group_col = group_col
        self.target_col = target_col
        self.group_medians_ = {}
        self.global_median_ = 0.0

    def fit(self, X: pd.DataFrame, y=None):
        # Data Leakage 방지를 위해 Fit 단계에서 오직 Train 데이터의 통계량만 산출하여 저장
        self.global_median_ = X[self.target_col].median()
        self.group_medians_ = X.groupby(self.group_col)[self.target_col].median().to_dict()
        return self

    def transform(self, X: pd.DataFrame) -> pd.DataFrame:
        X_out = X.copy()
        # 각 행의 결측치를 그룹 통계값으로 매핑, 미관측 그룹은 전역 통계값(Fallback)으로 대체
        impute_values = X_out[self.group_col].map(self.group_medians_).fillna(self.global_median_)
        X_out[self.target_col] = X_out[self.target_col].fillna(impute_values)
        return X_out
```

## 5. 통계적 이상치 탐지: IQR (Tukey's Fences) 수학적 정식화
이상치(Outlier)는 데이터 생성 프로세스(Data Generating Mechanism)의 주류 분포로부터 현저히 벗어난 관측치입니다.

### 5.1 사분위수 및 IQR 정의
확률변수 $X$의 누적분포함수를 $F(x) = P(X \le x)$라 할 때, $p$-분위수는 $Q(p) = F^{-1}(p)$입니다.
- 제1사분위수: $Q_1 = F^{-1}(0.25)$
- 제3사분위수: $Q_3 = F^{-1}(0.75)$
- 사분위범위(Interquartile Range):
  $$IQR = Q_3 - Q_1$$

### 5.2 Tukey의 울타리(Tukey's Fences) 공식
$$Inner\ Fences: [Q_1 - 1.5 \times IQR, \;\; Q_3 + 1.5 \times IQR]$$
$$Outer\ Fences: [Q_1 - 3.0 \times IQR, \;\; Q_3 + 3.0 \times IQR]$$
통상적으로 관측치 $x_i$가 $[Q_1 - 1.5 \times IQR, Q_3 + 1.5 \times IQR]$ 범위를 벗어나면 Mild Outlier, Outer Fences를 벗어나면 Extreme Outlier로 판정합니다.

> **정규분포와의 통계적 대응 관계:**
> $X \sim \mathcal{N}(\mu, \sigma^2)$일 때, $Q_1 \approx \mu - 0.6745\sigma$, $Q_3 \approx \mu + 0.6745\sigma$, $IQR \approx 1.349\sigma$입니다.
> 따라서 $Q_3 + 1.5 \times IQR \approx \mu + 0.6745\sigma + 1.5(1.349\sigma) \approx \mu + 2.698\sigma$가 되어, 가우시안 분포 가정 하에서 양측 꼬리 약 $0.7\%$의 이상치 기준과 통계적으로 일치합니다.

## 6. 결측 메커니즘과 조건부 그룹 대치 (Group Imputation)
결측 데이터는 Rubin의 분류 체계에 따라 세 가지로 구분됩니다.
1. **MCAR (Missing Completely at Random)**: 결측 확률이 관측/미관측 변수 전체와 완전히 독립적 ($P(M|Y_{obs}, Y_{mis}) = P(M)$).
2. **MAR (Missing at Random)**: 결측 확률이 오직 관측된 다른 변수 $Y_{obs}$에만 의존적 ($P(M|Y_{obs}, Y_{mis}) = P(M|Y_{obs})$).
3. **MNAR (Missing Not at Random)**: 결측 확률이 결측된 값 자체에 의존적 ($P(M|Y_{obs}, Y_{mis}) = P(M|Y_{mis})$).

이커머스 결측치(e.g., 특정 등급 고객의 나이 누락)는 주로 **MAR** 메커니즘을 따릅니다. 따라서 전역 단변량 대치(Mean/Median) 대신, 관측된 범주 $G$에 대한 조건부 기댓값 $E[X \mid G=g]$ 혹은 조건부 중위수 $\text{Med}(X \mid G=g)$를 추정하여 대치함으로써 추정 편향(Bias)을 최소화합니다.

## 7. 탐색적 데이터 분석(EDA) 통계적 시각화 기법 6선

```
+--------------------------------------------------------------------------+
| 1. Hist + KDE        2. Tukey Boxplot      3. Correlation Heatmap        |
|  f(x)                  ┌──┬──┐               Var1 [ 1.0  0.8 -0.2 ]      |
|   /\    _              │  │  │---o           Var2 [ 0.8  1.0  0.1 ]      |
|  /  \__/ \             └──┴──┘               Var3 [-0.2  0.1  1.0 ]      |
+--------------------------------------------------------------------------+
| 4. Scatter & OLS     5. Error Bar Chart    6. Time Series Decomposition  |
|  y ^   . /'            |    ┌─┐              Trend:   /‾‾\_              |
|    |  / .              | ┌─┐│ │              Season: /\/\/\              |
|    +------> x          +-┴─┴┴─┴-             Resid:  ..-.-.              |
+--------------------------------------------------------------------------+
```

1. **Histogram & Kernel Density Estimation (KDE)**: 
   경험적 확률밀도함수 $\hat{f}_h(x) = \frac{1}{nh} \sum_{i=1}^n K\left(\frac{x - x_i}{h}\right)$를 통해 데이터의 왜도(Skewness)와 첨도(Kurtosis)를 진단.
2. **Tukey Box Plot**:
   중위수(Med), 사분위범위(IQR), 극단값을 동시에 시각화하여 비대칭 분포와 이분산성(Heteroscedasticity) 확인.
3. **Correlation Heatmap**:
   피어슨 선형 상관계수 $r = \frac{\sum (x-\bar{x})(y-\bar{y})}{\sqrt{\sum (x-\bar{x})^2 \sum(y-\bar{y})^2}}$ 또는 스피어만 순위 상관계수의 행렬을 컬러 매핑하여 다중공선성(Multicollinearity) 검출.
4. **Bivariate Scatter Plot with OLS Regression**:
   두 연속형 피처 간의 선형/비선형 의존 구조 및 잔차의 등분산성 검토.
5. **Categorical Bar Plot with Confidence Interval**:
   부트스트랩(Bootstrap) 95% 신뢰구간 에러바를 동반하여 범주 간 모평균 차이의 통계적 유의성 시각화.
6. **Time-Series Decomposition Plot**:
   시계열 관측치 $Y_t = T_t + S_t + I_t$ (가법) 또는 $Y_t = T_t \times S_t \times I_t$ (승법)로 분해하여 추세, 주간/월간 계절성, 잔차(노이즈)의 분산 구조 분석.

## 8. RFM 수리 모델 및 고객 세분화 알고리즘

### 8.1 지표의 정량화 정의
특정 기준 시점 $T_{ref}$와 고객 $u$의 주문 집합 $\mathcal{D}_u = \{(t_{u,1}, m_{u,1}), (t_{u,2}, m_{u,2}), \dots, (t_{u,n_u}, m_{u,n_u})\}$에 대해:
- **Recency ($R_u$)**:
  $$R_u = T_{ref} - \max_{i=1, \dots, n_u}(t_{u,i})$$
- **Frequency ($F_u$)**:
  $$F_u = n_u = |\mathcal{D}_u|$$
- **Monetary ($M_u$)**:
  $$M_u = \sum_{i=1}^{n_u} m_{u,i}$$

### 8.2 분위수(Quantile) 스코어링 및 가중 합성 스코어
각 지표를 단변량 분위수 분할(5분위, $q \in \{1, 2, 3, 4, 5\}$)로 매핑합니다.
- $R$은 작을수록 최근이므로 역순 할당: $S_R = 6 - \text{QuantileRank}(R_u)$
- $F, M$은 클수록 우수하므로 정순 할당: $S_F = \text{QuantileRank}(F_u)$, $S_M = \text{QuantileRank}(M_u)$
- **가중 RFM 총점 (Composite RFM Score)**:
  $$\text{Score}_{RFM} = w_R S_R + w_F S_F + w_M S_M \quad \left(\sum w_i = 1\right)$$

### 8.3 4개 이상 다차원 세그먼트 규칙 및 군집화
스코어 벡터 $\mathbf{s}_u = (S_R, S_F, S_M)$에 기반하여 규칙 기반 매핑 또는 $K$-Means 알고리즘을 적용합니다:

```
           High F ^
                  |   [Loyal Customers]     [Champions / VIP]
                  |   (High F, Med/Low R)   (High R, High F, High M)
                  |
                  |   [Hibernating / Lost]  [New Customers]
                  |   (Low R, Low F, Low M) (High R, Low F, Low M)
                  +------------------------------------------------>
                                                         High R
```

1. **Champions (VIP, 최상위 고객)**: $S_R \ge 4 \land S_F \ge 4 \land S_M \ge 4$. 매출 기여도 극대화, 로열티 보상 프로그램 유지.
2. **Loyal Customers (충성 단골)**: $S_R \ge 3 \land S_F \ge 3 \land S_M \ge 3$. 크로스셀링(Cross-selling) 및 업셀링(Up-selling) 전략 타깃.
3. **At Risk / Churn Warning (이탈 위험군)**: $S_R \le 2 \land S_F \ge 3 \land S_M \ge 3$. 과거 고가치 고객이었으나 최근 이탈 징후 포착. 리인게이지먼트 윈백(Win-back) 프로모션 대상.
4. **New Customers (신규 유입군)**: $S_R \ge 4 \land S_F \le 2$. 온보딩 시퀀스, 첫 구매 감사 할인 등을 통한 $F$ 증대 전략 필요.
5. **Hibernating / Lost (동면/이탈 고객)**: $S_R \le 2 \land S_F \le 2 \land S_M \le 2$. 마케팅 비용 투입 제한(최소화), 자동화된 주기적 브랜딩 뉴스레터만 노출.

## 9. 비즈니스 의사결정 및 경제성 모델 (CLV & Churn)
단순 세그먼트 도출을 넘어 단위 경제학(Unit Economics) 지표로 연결해야 합니다.
- **고객 생애 가치 (Customer Lifetime Value, CLV)**:
  $$\text{CLV} = \sum_{t=0}^{\infty} \frac{(\text{Margin}_t - \text{Cost}_t) \cdot r^t}{(1 + d)^t} \approx \frac{\text{AOV} \times \text{Purchase Frequency} \times \text{Gross Margin}}{\text{Churn Rate}}$$
  ($\text{AOV}$: 평균 주문 금액, $r$: 리텐션율, $d$: 할인율)
- **최적 프로모션 ROI 산출**:
  $$\mathbb{E}[\Delta \Pi] = N_{\text{target}} \times \left( \Delta P_{\text{retention}} \times \text{CLV} - C_{\text{campaign}} \right)$$
  이탈 위험 세그먼트에 쿠폰($C_{\text{campaign}}$)을 지급할 때 리텐션 증가 확률($\Delta P_{\text{retention}}$)에 따른 기대 이익 $\mathbb{E}[\Delta \Pi]$이 양(+)이 되는 임계점(Break-even Point)을 도출하여 의사결정을 자동화합니다.

# A1-1 쇼핑몰에서 누가 자주 오고 많이 사는지 분석해서 단골 찾기

이커머스 플랫폼의 멀티모달(수치, 범주, 날짜, 텍스트, 이미지 배열) 데이터를 객체지향(OOP) 파이프라인으로 정제하고, 정밀 탐색적 데이터 분석(EDA)과 RFM(Recency, Frequency, Monetary) 기법을 적용하여 고객을 세분화하고 데이터 근거 기반 비즈니스 전략을 수립한 프로젝트입니다.

---

## 1. 프로젝트 개요

- **도메인**: 이커머스 거래 로그 및 멀티모달 메타데이터 분석
- **핵심 목표**:
  1. NumPy 벡터 연산을 활용해 고차원 이미지 텐서와 텍스트 특성을 단일 데이터프레임으로 통합하는 객체지향 `DataAnalyzer` 파이프라인 구축
  2. 그룹별(GroupBy) 결측치 대치 및 IQR 방식의 이상치 탐지/클리핑 알고리즘 직접 구현
  3. 6종 필수 시각화(히스토그램, 박스플롯, 막대그래프, 히트맵, 산점도, 라인차트)를 통한 정량적 데이터 해석
  4. RFM 점수화(분위수 기반)를 통한 5대 고객 세그먼트 발굴 및 비즈니스 액션 플랜 3종 도출

## 4. 데이터 분석 파이프라인 아키텍처 (`src/pipeline.py`)

`DataAnalyzer` 클래스는 절차형 스크립트가 아닌 재사용 가능한 객체지향(OOP) 구조로 설계되었습니다.

1. **`load_data(csv_path, img_path)`**:
   - 거래 데이터 CSV와 고차원 이미지 NumPy 배열을 한 번에 로드하고 날짜형 인덱싱을 수행합니다.
2. **`extract_multimodal_features()`**:
   - `np.mean(images, axis=(1, 2, 3))` 및 `np.std(images, axis=(1, 2, 3))`를 활용해 for loop 없이 1,500개 이미지의 통계량을 벡터 연산으로 단번에 산출합니다.
   - 상품명의 어절 수와 문자열 길이를 수치 피처로 변환합니다.
3. **`handle_missing_values(strategy='group_median', target_col='customer_age', group_col='category')`** (요구서 표기 `handle_missing()`도 같은 동작을 하는 alias로 제공):
   - 단순 전체 평균 대치가 야기하는 편향을 방지하기 위해 `groupby(group_col)[target_col].transform()` 기반의 세부 그룹별 통계 대치를 수행합니다.
4. **`detect_outliers(column='amount', iqr_multiplier=1.5, action='clip')`**:
   - 사분위수(Q1 36,100원, Q3 132,050원, $IQR = 95,950$원)를 직접 계산해 상한 **275,975원**을 산출하고, 이를 벗어난 162건(10.8%)을 탐지합니다.
   - 탐지된 162건 중 **Electronics가 102건**(해당 카테고리 335건의 30%)입니다. 단가가 높은 카테고리는 구조적으로 상한을 넘기므로, 이 집합은 "오류값"이 아니라 **고가 정상 결제가 다수 포함된 집합**으로 해석해야 합니다.
   - `amount_clipped`는 분포·상관 분석용으로만 사용하며, 클리핑으로 줄어드는 금액은 전체 결제액의 **29.0%**입니다. 따라서 매출 집계와 RFM Monetary는 원본 `amount` 기준을 유지합니다.
5. **`calculate_rfm(reference_date=None)`**:
   - 데이터 최종 거래일 + 1일을 분석 기준일로 설정하여 고객별 Recency, Frequency, Monetary를 집계합니다.
   - **평균 순위(average rank)의 백분위 기반으로 1~4점**을 부여합니다. 동점 고객은 동일한 점수를 받으며, 점수별 고객 수는 실제 데이터 분포에 따라 달라집니다.
   - 세그먼트는 **위에서부터 먼저 만족하는 규칙**으로 확정되며, `New`(최근성 높음 + 주문 1건)를 `Loyal`보다 **앞에** 두어 실제로 도달 가능한 세그먼트로 만듭니다.

## 6. 데이터 기반 비즈니스 인사이트 3종 (근거 - 실행 - 검증)

### 인사이트 1: 매출 절반을 견인하는 VIP 세그먼트의 프리미엄 멤버십 락인(Lock-in) 전략
- **(근거)**: 전체 고객 327명 중 VIP는 **94명(28.7%)**인데 전체 매출의 **53.8%**를 차지합니다. VIP의 평균 구매 빈도는 **8.1회**로 이탈 고객(1.9회)의 **4.3배**이고, 평균 Recency는 **21.1일**입니다.
- **(실행)**:
  - **대상 세그먼트**: `VIP` 94명 **전원** (세그먼트 비율이 28.7%이므로 "상위 1%" 대상이 아닙니다. 1%로 좁히려면 별도의 예산·전략적 판단 기준이 필요합니다.)
  - **실행 방법**: 무료 반품, 신상품 24시간 우선 구매권, 무료 배송 바우처를 결합한 전용 멤버십을 제공합니다.
  - **기대 효과**: VIP 1인당 연간 구매가 8.1회 → 9.1회(+1회)로 늘면 플랫폼 총매출은 약 **+6.6%**입니다(`53.8% × 1/8.1`).
- **(검증)**: 재구매 주기 단축을 확인하려면 고객별 월별 세션·장바구니 로그가 추가로 필요하며, VIP가 혜택과 무관하게 원래 충성도가 높았을 가능성(내생성)을 A/B 테스트로 반증 검증해야 합니다.

---

### 인사이트 2: 고가치 이탈 우려군(`At_Risk`) 대상 윈백(Win-back) 타깃 프로모션
- **(근거)**: `At_Risk` 72명(22.0%)이 전체 매출의 **29.5%**를 차지합니다. 1인당 평균 누적 구매액 **856,999원**, 평균 구매 빈도 **4.9회**로 VIP(8.1회)에 뒤지지 않는 고가치군이지만, 평균 Recency가 **107.8일**로 VIP(21.1일)의 약 5.1배입니다. 세그먼트 누적 구매액은 72 × 856,999 ≈ **6,170만원**입니다.
- **(실행)**:
  - **대상 세그먼트**: `At_Risk` (72명)
  - **실행 방법**: 과거 구매 카테고리(패션·전자기기 등)의 신상품 큐레이션과 15% 웰컴백 쿠폰(7일 한정)을 알림톡/앱 푸시로 발송합니다.
  - **기대 효과**: 재진입률 20%를 가정하면 약 **14명**(72명의 20%)이 재방문할 것으로 예상됩니다. 재방문 고객의 과거 평균 누적 구매액(856,999원)을 기준으로 한 **대상 고객의 과거 구매액 규모**는 `72명 × 856,999원 × 20% ≈ 1,234만원`입니다. 이는 **미래 매출 예측값이 아니며**, 실제 매출 효과는 재방문 후 구매액으로 검증해야 합니다.
- **(검증)**: 타사 전환 여부를 파악하려면 미방문 사유 설문 데이터가 필요하며, 할인 쿠폰이 일회성 체리피킹으로 끝날 가능성을 추적해야 합니다. 또한 본 수치는 "과거 누적액"이므로 재방문이 곧 동일 금액의 재발생을 의미하지는 않습니다.

---

### 인사이트 3: 객단가 극대화를 위한 상품 묶음 번들(Bundle) 프로모션 및 크로스셀링
- **(근거)**: 주문의 **58.9%가 단일 수량**, 2개 이상 구매는 **41.1%**이며 평균 구매 수량은 **1.75개**, 클리핑 기준 객단가는 **99,066원**입니다. 한편 `amount_clipped`와 단가(0.74)·수량(0.47)의 상관은 **`amount = unit_price × quantity`라는 정의에서 구조적으로 발생하는 값**이므로 "발견"이 아니라 정의 수준의 사실입니다(0.47을 "매우 강한" 상관으로 서술하지 않습니다). 연령과 결제 금액의 상관은 **0.017**로 사실상 무관합니다.
- **(실행)**:
  - **대상 세그먼트**: `Loyal` (55명) 및 `New` (7명) 우선
  - **실행 방법**: 2개 이상 구매 시 10% 번들 할인과 장바구니 단계의 연관 카테고리 추천 위젯을 도입합니다.
  - **기대 효과**: 평균 구매 수량이 1.75개 → 2.0개로 오르면(단가·할인 미반영 가정) 객단가도 **+14.3%** 수준의 방향성 변화를 기대할 수 있습니다.
- **(검증)**: 번들 할인이 마진을 훼손하지 않는지 상품별 원가율 데이터가 필요하며, 다량 구매가 이후 재구매 주기를 오히려 늘리는 수요 선반영(Cannibalization) 가능성을 점검해야 합니다.

## 7. ML 확장 계획 (이탈 예측)

현재 분석은 **규칙 기반 RFM 세그먼테이션**까지입니다. 다음 단계로 "누가 떠날 것인가"를 예측하는 지도학습으로 확장합니다.

- **예측 문제**: 고객별 **`churn_90d` 이진 분류** — 기준일 이후 90일 내 주문이 없으면 1.
  - 주의: 현재 `Churned`/`At_Risk` 세그먼트는 **규칙으로 만든 라벨**이므로 이를 정답으로 재사용하면 순환 논리가 됩니다. 반드시 **미래 구매 여부**로 라벨을 별도 생성해야 합니다.
- **입력 피처(예상 목록)**

| 구분 | 피처 |
| :--- | :--- |
| 거래 이력 (RFM) | `recency`, `frequency`, `monetary`, 평균 객단가(`monetary/frequency`), 최근 30·90일 주문 수 |
| 구매 주기 | 주문 간격 평균·표준편차, 최근 3개월 대 이전 3개월 구매 비중 |
| 상품 | 주 구매 카테고리(원-핫), 구매 카테고리 엔트로피(다양성), 평균 단가 |
| 고객 | `customer_age`, `customer_gender` (확보 시 가입 채널·등급 추가) |
| 텍스트 | `product_name_len`, `product_word_count`, 카테고리별 구매 비중 |
| 이미지 | `img_pixel_mean/std`, R·G·B 평균 — **현재는 카테고리 대리변수**이므로 실제 이미지 임베딩(CNN/ViT)으로 교체 필요 |

- **검증 설계**: 시간 기준 분할(2025-01~09 학습 / 2025-10~12 평가)로 미래 정보 누수를 막고, 규칙 기반 `At_Risk` 대비 ROC-AUC·PR-AUC·F1을 비교합니다. 전처리(대치·스케일러)는 학습 구간에서만 `fit`합니다.
- **리스크**: 합성 데이터의 라벨은 실제 이탈 행태를 반영하지 않으므로, 이 단계는 실데이터 확보 후 수행해야 의미가 있습니다.
